abstract: >-
  BAS-VLA calibrates a frozen vision-language-action policy to respond to changes in what the robot should do. Its main calibration path redirects actions when a target object or task constraint changes. A selective auxiliary corrects drift caused by changes in appearance when there is strong evidence that the task itself is unchanged. Across four target-object swaps, success on the new task rises from 2.3% to 68.5%, and the policy is less likely to execute the old task. On task-preserving style shifts, success rises from 42% to 70% while clean performance holds.
